# Foyer

Foyer is a QuickShell desktop shell with a menu bar, notifications, an
on-screen display, an application launcher, and a Wi-Fi interface. A Rust
service provides application search for the launcher.

## Layout

- `quickshell/`: QML components and the configuration template.
- `shell-server/`: application-search service and its Rust development shell.
- `nix/home-manager.nix`: Home Manager integration, configuration generation,
  and user services.

The Home Manager module currently depends on this dotfiles repository's
`desktop.*` options. This directory is the starting point for extracting Foyer
into a standalone project; it does not yet provide an independent configuration
interface or CLI.

## Development

From this directory, launch the Wi-Fi interface:

```bash
quickshell -p quickshell/nmtui.qml
```

Run the application-search service:

```bash
cd shell-server
nix develop
cargo run
```

The bar and application launcher use configuration generated by the Home Manager
module, including `config.js` and the `Cmds` QML module.
